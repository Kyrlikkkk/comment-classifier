# Comment Classifier

## Описание проекта

Comment Classifier - веб-приложение для определения тональности
текстовых комментариев. Приложение позволяет определить,
является ли комментарий положительным или отрицательным.

В приложении предусмотрена регистрация и вход пользователя,
а также просмотр профиля и истории выполненных запросов.

## Основные экраны

- Главная страница
- Страница входа
- Страница регистрации
- Страница классификатора
- Профиль пользователя с историей запросов

## Основные пользовательские сценарии

1. Пользователь открывает главную страницу приложения.
2. Нажимает кнопку «Начать работу».
3. Переходит на страницу входа.
4. Если у пользователя нет аккаунта, он переходит на страницу регистрации.
5. После регистрации пользователь возвращается на страницу входа.
6. После входа пользователь переходит в профиль.
7. Из приложения пользователь может перейти к классификатору.
8. Пользователь вводит комментарий и запускает его анализ.
9. Приложение определяет тональность комментария.
10. Результат запроса сохраняется в истории пользователя.
